# 엑셀로 포지션별 속도·이동거리 구하기

축구 트래킹 데이터(`soccer_rawdata.xlsx`)로 실습한 엑셀 작업 순서입니다.

## 데이터 구조

| 항목 | 내용 |
|---|---|
| 선수 | 11명 (4-3-3): GK, RB·RCB·LCB·LB, DM·RCM·LCM, RW·ST·LW |
| 열 | A: Frame, B: Time_s, C~X: 선수별 x·y 좌표 (m), 2열씩 |
| 샘플링 | 0.1초 간격 (10Hz), 27,000프레임 = 45분 |
| 좌표 | x: 경기장 폭 방향 (0~68m), y: 길이 방향 (0~105m, 클수록 상대 골대 쪽) |

## 1. 프레임별 속도 (Sheet1)

속도 = √((x₂ − x₁)² + (y₂ − y₁)²) ÷ (t₂ − t₁) → 단위 m/s

GK 하나만 구할 때 (Z3):
```
=SQRT((C3-C2)^2+(D3-D2)^2)/(B3-B2)
```

11명을 한 번에 구할 때 (Z3에 넣고 AJ3까지 오른쪽으로 끈 뒤 아래로 채움):
```
=SQRT((INDEX($C3:$X3,2*COLUMN(A$1)-1)-INDEX($C2:$X2,2*COLUMN(A$1)-1))^2+(INDEX($C3:$X3,2*COLUMN(A$1))-INDEX($C2:$X2,2*COLUMN(A$1)))^2)/($B3-$B2)
```
- `COLUMN(A$1)`이 오른쪽으로 갈수록 1, 2, 3…이 되면서 GK, RB, RCB… 순서로 x·y 열을 찾아감
- 머리글 Z1~AJ1: `GK_v, RB_v, RCB_v, LCB_v, LB_v, DM_v, RCM_v, LCM_v, RW_v, ST_v, LW_v`

**2만 7천 행 채우기:** 이름 상자에 `Z3:AJ27001` 입력 → Enter → **Ctrl + D**
(바로 왼쪽 열이 비어 있으면 채우기 핸들 더블클릭이 작동하지 않음)

## 2. 요약표 (Sheet2)

| 셀 | 수식 |
|---|---|
| A2~A12 | GK, RB, RCB, LCB, LB, DM, RCM, LCM, RW, ST, LW |
| B2 평균 속도 (km/h) | `=AVERAGE(INDEX(Sheet1!$Z$3:$AJ$27001,0,ROW(A1)))*3.6` |
| C2 최고 속도 (km/h) | `=MAX(INDEX(Sheet1!$Z$3:$AJ$27001,0,ROW(A1)))*3.6` |
| D2 이동거리 (km) | `=SUM(INDEX(Sheet1!$Z$3:$AJ$27001,0,ROW(A1)))*0.1/1000` |

B2:D2를 12행까지 끌어서 채움. `ROW(A1)`이 1, 2, 3…이 되면서 속도 열을 차례로 가리킴.

- m/s → km/h: × 3.6
- 이동거리: 속도 × 0.1초를 모두 더함 (= 프레임 간 거리의 합)

## 3. 겪은 문제

| 증상 | 원인 / 해결 |
|---|---|
| 채우기 핸들 더블클릭이 안 됨 | 왼쪽 열이 비어 있음 → 이름 상자로 범위 지정 후 Ctrl + D |
| 속도가 음수로 나옴 | 수식 열을 **복사**해서 옮기면 참조가 같이 밀림 → 옮길 때는 **잘라내기(Ctrl + X)**, 또는 `$`로 열 고정 |
| `#DIV/0!` | 참조한 범위가 비어 있음 (시트 이름이나 열 위치 확인). `=COUNT(Sheet1!Z3:Z27001)`로 개수 확인 |

## 4. 주의: 노이즈

0.1초 간격 원본 좌표에는 작은 떨림이 있어서, 그대로 계산하면 이동거리와 최고속도가 실제보다 크게 나옵니다. 최고속도 35~39km/h는 세계 최정상급 스프린터 수준이라 과대평가된 값입니다.
- 간단한 대안: 1초(10프레임) 간격으로 속도 계산 `=SQRT((C13-C3)^2+(D13-D3)^2)/(B13-B3)`
- 정식으로는 저역통과 필터를 적용한 뒤 계산합니다.
