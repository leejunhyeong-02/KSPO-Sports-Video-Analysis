## 1. 오전 — OpenCap 셋업 절차 (시연 기준)

### 1-1. 세션 생성 ~ 폰 연동
1. OpenCap 웹 로그인 → **New Session**
2. 카메라 **1대 / 2대** 모드 선택 (최근 1대 모드 추가됨, 시연은 2대)
3. 아이폰에 OpenCap 앱 설치·업데이트 → 앱 실행 → 화면의 **QR 스캔** → `Session joined`
4. 미니 삼각대에 폰 거치 (세로/가로는 측정 동작에 맞춰 선택)

**연동 팁**
- 폰을 PC 앞까지 가져가서 QR 찍기 번거로움 → **다른 폰으로 QR을 사진 찍어** 삼각대에 거치된 폰에 인식시키면 편함
- 촬영 중 **문자/전화 오면 연동 끊김**. 비행기 모드는 PC 연동 자체가 끊기므로 불가 → 방해금지 정도로 대응
- 카메라 **위치가 바뀌면 반드시 재캘리브레이션**

### 1-2. 캘리브레이션 (체커보드)
- 기본 제공 체커보드: **4×5, 35mm** (더 큰 공간이면 크게 출력하고 설정값 수정)
- **반드시 평평한 판**에 부착해야 함 (휘면 길이가 달라져 캘리브레이션 오류)
- 화면 중앙쯤에 보이게 두고 **한 번만** 촬영 → 2대 영상 업로드 → 처리 → 완료되면 체커보드 치워도 됨
- 캘리브레이션 결과물: `CalibrationImages` 폴더에 3축이 그려진 이미지 저장 (축 방향이 우리가 생각한 것과 다를 수 있음 → 분석 시 확인)

### 1-3. 피험자 정보 입력
- 이름, 몸무게(kg), 키(m), 출생연도 등 (필수 아님)
- Subject tag: 질병군/장애군 분류 가능, 해당 없으면 **Unimpaired**
- 피험자 동의 확인 체크
- Session name 입력 (예: `2026_test`)
- **Data sharing**: OpenCap 측 연구용 공유 여부. 공유 안 해도 불이익 없음. Raw / Processed / Identified video 단위로 선택

### 1-4. Advanced settings
| 항목 | 내용 |
|---|---|
| Pose estimation 모델 | **HRNet (기본, 권장)** / OpenPose. MediaPipe 등과의 차이는 각자 공부 |
| Frame rate | **60Hz면 보행 등 일반 동작 충분** (인간 눈 ~30Hz). 120Hz = 저장·처리 2배, 240Hz = 4배. 아이폰 슬로모는 240까지 |
| Musculoskeletal model | 기본값 사용 (Full body with ISB shoulder 등 옵션 있음) |

### 1-5. 촬영
1. **Record Neutral Pose** — 정면 보고 가만히 서기. 3D 분석 시스템은 모두 이 단계를 요구함 (키·체형을 반영해 뼈대 모델 생성)
2. 이후 **Dynamic trial** — trial 이름 붙이고 Start → 동작 → Stop
3. 상태 표시
   - 🔴 빨강: 레코딩 실패
   - 🟡 노랑: 저장 완료, 서버 처리 중 (보통 5~10분, 서버 불안정 시 길어짐)
   - 🔵 파랑: 처리 완료
   - 노랑 상태에서 **다음 촬영 계속 가능** (서버 일이므로 기다릴 필요 없음)

### 1-6. 데이터 다운로드
- 세션 → Dashboard(Kinematics 그래프, 이미지 복사해서 리포트에 바로 사용 가능) → **Download data** → zip
- 구성
  - `MarkerData/*.trc` — 키포인트 XYZ 좌표 (엑셀로 열림). **모든 키네메틱 변인의 원천 데이터**
  - `OpenSimData` — 근골격 시뮬레이션용 (OpenSim은 무료, 근활성도 추정 가능하나 별도 공부 필요)
  - `Videos`
  - `CalibrationImages`
- raw data를 GPT에 던져 변인 추출·리포트 생성도 가능 → "쓰냐 안 쓰냐의 문제"

### 1-7. 오늘 에러 기록
- 증상: Neutral pose 처리 에러 반복 (강사님도 처음 겪음)
- 시도: 재촬영, 거리 조정, 체커보드 테이프 고정 후 재캘리브레이션 → 모두 실패
- 추정 원인: 체커보드가 평평하지 않았음(노트북/의자/책에 걸침), 공간 협소·가려짐, 캘리브레이션 불량
- 조치: 다음 주 **플라스틱 판에 체커보드 4개** 준비해 옴, **OpenCap 한글 매뉴얼 PDF(7~8p)** 단톡방 공유 예정

### 1-8. 조 편성 (삼각대 6개 → 3조)
- 야구 + 웨이트 (합침)
- 복싱
- 보행
- 주짓수·유도·레슬링 등 **2인 접촉 종목은 occlusion(가려짐) 때문에 불가**. 복싱은 1인 자세 분석이면 가능

### 1-9. 작년 수강생 사례
- 피트니스 짐 운영자 2명이 고객용 차별화로 OpenCap 배워감 → 현장 적용이 번거롭고 공부가 더 필요해 결국 **안 씀**
- "25명 중 내년에도 쓰는 사람은 1~2명. 하냐 안 하냐의 문제."

## 2. 오후 1부 — 움직임 분석 이론 리프레시

### 2-1. 이벤트와 페이즈 (분석의 1단계)
- 사람마다 다른 동작을 **같은 동작으로 정량화·비교**하려면 시점(이벤트)과 구간(페이즈) 정의가 먼저. 이게 없으면 어떤 분석도 불가
- 보행 이벤트는 2개뿐: **발 닿음(heel strike) / 발 떨어짐(toe off)**
  - 1 보행 주기 = 닿음 → 떨어짐 → 다시 닿음
  - Stance phase : Swing phase ≈ **6 : 4** (평균일 뿐, 속도·환경·개인에 따라 달라짐. 6:4 아니면 비정상이라는 뜻 아님)
- 보행 vs 러닝 차이 = **양발 지지(double support) 구간 유무**
- 피칭도 마찬가지: 준비 → 와인드업 → 무릎 올림 → 스트라이드 → 릴리스 등 메카닉적으로 중요한 시점을 먼저 정의

### 2-2. "정답은 없다" — 반복 강조된 철학
- 러닝 풋스트라이크(리어/미드/포어), 케이던스, 슬로우 러닝, 지면반력 "세게 누르기", 인솔 아치 교정 → 모두 **개인차가 커서 표준화 불가**
- 지면을 세게 누르면 상지 보상력도 커야 함. 살살 눌러도 효율적일 수 있음 → "무조건 근력·세게"는 섣부른 주장
- 딱딱한 아치 인솔 업체들이 4~5년 전 수십 개 → 통증 호소자 늘며 대부분 사라짐
- 솔루션을 팔려면 기준을 주장해야 하지만, 인간 움직임은 리스크가 큼. 전문가라면 **분별력**을 갖춰야
- 평균·표준편차로 인간 움직임의 "잘했다/못했다"를 판정하는 건 이미 한계

### 2-3. 균형 (강사 주 연구분야)
- 보행 = 무게중심을 앞으로 내밀고 넘어지지 않으려 발을 내딛는 **연속적인 균형 유지**
- 핵심 변인: **COM(신체 무게중심), BOS(기저면), COP(압력중심)**
- COP = 전신 움직임이 지면에 반영된 최종 결괏값. 역추적으로 자세·움직임 파악 가능
- 전통 분석: COP 이동 범위·속도·거리 → 범위 크면 균형 나쁨? **이것만으로 판정 불가**
- 발전 방향: COP **패턴 분석** (dynamical systems theory, 복잡성) → 파킨슨·뇌졸중·뇌진탕 판별 방법론 존재
- 눈 감고 한 발 서기는 영상 분석으로 잘 안 잡힘
- 랩 진행 과제 예: 노인 낙상, 음주 균형 — **혈중알코올 0.05 상승기 vs 하강기의 균형 차이** (IRB 승인, 실제 음주 실험)

### 2-4. e스포츠 예시
- 페이커: 13년 폼 유지 비결 중 하나가 **타이밍·인지 훈련**. QWER 입력 하나에 아군·적군·쿨타임 정보 처리가 들어감
- 브리온 팀은 선수 대상 이런 연구 진행 중 → 동작 분석의 적용 범위는 매우 넓음

### 2-5. 논문·대학원 Q&A (대학원생 질문에 대한 답)
- 연구 설계·피험자 수에 정답 없음. **이론과 방법론 절차에서 벗어나지 않으면** 어떤 결과든 해석해도 됨
- 인트로 문단 수·문장 수 규칙 없음. **논리만 맞으면 됨**. "과학적 워딩" 같은 것도 없음
- 리뷰어는 만물박사가 아님. 절차·이론 준수 여부를 보는 정도
- 유학을 가야 하는 이유 = **"돈이 안 든다."** 박사 유학은 100% 지원받음. 부수적으로 환경·네트워크도 따라옴
- 대학원은 기회비용(6~7년)이 크므로 기본적으로 비추천. 단, 학위가 필요한 자리(연구원 등)에선 학위가 **가장 쉬운 증명 수단**
- 교수 메리트: 사립대 연봉 10여 년 동결, 연금 반토막. 사업(벡터바이오) 시절 수입의 1/5. 대신 독립적 연구 환경
- 사업: 매일 매출 스트레스, 직원 10명이면 연 운영비 ~1억. 아이템이 확실하면 할 만함 (러닝 데이터 → 신발 추천 솔루션, 테니스 앱 '스매시' 협업 사례)
- 커리어 전환 나이: 37도 안 늦음. 강사 본인도 30살에 박사 유학, "모두 0에서 시작"
- 대학원생 = 노동자·복종하는 시대는 지남. 연구 한 편 완성해 본 사람과 아닌 사람의 격차는 큼 → 자랑스러워해도 됨

### 2-6. 최신 논문 소개 — 자동 이벤트 검출
- 저널: **Sports Biomechanics** (운동역학 분야 좋은 저널)
- 내용: Simi 마커리스(카메라 8대)로 **실제 테니스 경기** 촬영 → 키네마틱 데이터 추출 → **라켓-볼 임팩트 시점을 딥러닝으로 자동 검출**
- 왜 중요한가: 이벤트 라벨링은 전처리 중 가장 시간이 많이 드는 작업(과거엔 수기로 1~2년). 마커리스 빅데이터 + AI로 자동화
- 리뷰어 반박 없음. "이벤트를 여기로 정한 게 틀렸다"고 아무도 말할 수 없음 (정해진 규칙이 없으므로)
- 데이터 수집·알고리즘 1년, **집필은 3일**
- 응용: 골프·탁구·배드민턴 등 다른 종목에 같은 틀 적용 → 연구도, 사업 아이템도 가능. 야구에도 진행 중

## 3. 오후 2부 — Visual3D

### 3-1. 개요
- 3D 동작분석 데이터(모캡, 마커리스, IMU, 힘판, EMG)를 **한 프로그램에서 통합 분석**하는 툴. "현존 가장 파워풀"
- 라이선스 **약 1,000만 원, 영구**. 무료 업데이트는 **1년**만 (이후 업데이트마다 유료 → 보통 마지막 버전 받고 계속 씀)
- UI는 윈도우 95 이전 느낌이나 기능은 계속 업데이트 중
- 원래 이 과정에서 3~4주 가르쳤으나 수강생 부담으로 반나절로 축소. 파이썬 등으로 대체 가능해진 것도 이유
- 그래도 생체역학·동작분석 하는 사람은 **기본값으로 배워두길 권장**. 특히 **모델링**과 **파이프라인**은 다른 툴로 구현하기 어려움

### 3-2. 데이터 흐름
```
모캡 촬영 (반사마커 + 적외선 카메라 / 마커리스)
  → 마커 라벨링 (어느 마커가 어느 부위인지)
  → C3D 파일 (동작분석 업계 표준 확장자, hwp/docx 같은 개념)
  → Visual3D import
  → 컴퓨터 눈엔 "허공의 하얀 점"일 뿐 → 신체 모델링 필요
  → 모델링 완료 → 파이프라인으로 변인 산출
```
- 메인 탭: **Signal and Event** (데이터·영상 뷰), **Model** (모델링), 파이프라인
- 좌측 트리: Target(=반사마커 하나하나) 클릭 → XYZ 좌표 시계열 바로 표시. 보행이면 Z 위아래 진동, Y 전진 패턴이 보임

### 3-3. 좌표계
- **글로벌 좌표계**: 캘리브레이션 시 생성. 오른손 기준 — 중지 **Z = 위**, 검지 **Y = 앞**, 엄지 **X = 오른쪽**
- 힘판도 같은 좌표계에 위치 등록 → 지면반력 벡터(빨간 화살표)가 동기화되어 표시
- 모캡·힘판·EMG·IMU를 한 번에 수집하면 **완전 동기화된 상태로** Visual3D에 들어옴

### 3-4. 신체 모델링 (Model 탭) — 핵심
- **Static trial (뉴트럴 포즈)** 을 먼저 찍고 거기에 뼈대를 입힘 → Dynamic trial에 적용
- 분절(segment) / 관절(joint) 개념. 신체 중심 가까운 쪽 = **proximal**, 먼 쪽 = **distal**. 안쪽 = **medial**, 바깥쪽 = **lateral**
- 분절 로컬 좌표계 생성 규칙 (이것만 기억):
  - **Z축**: distal → proximal
  - **X축**: medial → lateral
  - **Y축**: 둘에 직교, 앞 방향 (자동 생성)
- 순서: **골반(pelvis)부터** → 대퇴 → 하퇴 → 발. 신체는 kinematic chain이라 중심에서 말단으로 가야 자유롭게 생성됨
- 골반 모델링: **CODA 방식** — ASIS 2개(앞) + PSIS 2개(뒤) 마커로 뼈 생성 + 눈에 안 보이는 **고관절 중심 추정**. 고관절은 인종·성별 차이가 커서 추정 알고리즘 연구가 많음
- 모델링 방식은 마커셋에 따라 다양 → "내 연구에 최적인 모델링이 뭔가"도 하나의 연구 주제

### 3-5. 관절각 계산 원리
- 글로벌 기준이 아니라 **인접 분절 로컬 좌표계 간 상대 각도**
  - 무릎 각도 = **대퇴(reference segment) 기준 하퇴(segment)의 움직임**
- 축별 의미 (무릎 예)
  - X축 회전: **굴곡/신전**
  - Y축 회전: **내전/외전**
  - Z축 회전: **내회전/외회전**
- 부호: **오른손 법칙**. 신전(+), 굴곡(−) → 왜 그런지는 기능해부학 공부 필요

### 3-6. 파이프라인
- 명령어 하나하나 = 파이프. Visual3D에 **301개** 파이프 내장. 조합해서 raw data 던지면 결과까지 자동
- 예: `Compute_Model_Based_Data` → Joint angle / power / moment 등 선택 → reference segment, segment 지정 → 실행 → 새 데이터 생성
- 파이프라인 하나 잘 만들면 **10만 트라이얼도 한 번에, 통계까지 10분 내**. 파이썬으로도 되지만 같은 속도·논리로 짜는 건 별개의 실력
- 실수 사례: segment를 대퇴로 잘못 지정해 각도 0 → 하퇴로 수정 후 정상 출력

### 3-7. 데이터 품질 — 필터링·캘리브레이션
- 모든 데이터엔 노이즈 존재. 필터링은 한 학기 분량 주제, **반드시 해야 함**
- 캘리브레이션: 벡터바이오는 **피험자 한 명마다** 재캘리브레이션. 병원은 6개월~1년 안 하고, 과학원은 카메라 30대 걸어두고 안 함 → "그것밖에 안 된다"
- "데이터는 거짓말하지 않는다. 노력한 만큼 성장한다."

### 3-8. 현장 적용 / 다이나믹 종목
- 마커 부착·카메라 다수 필요 → 현장(빠른 수집 필요한 곳)에선 번거로움
- 수영 등 카메라 범위를 벗어나는 큰 동작: **IMU/GPS 센서**로 키네마틱 생성. 특정 기술(스트로크 한 동작)은 모캡·마커리스 가능하나 정확도 ↓
- "불가능한 건 없지만 가능하게 만드는 노력은 연구자 몫"

### 3-9. 기타

## 4. 내가 한 질문 & 답변

### Q. 선행연구가 없는 주제는 어떻게 연구를 시작하나? ✅
- 솔직히 어렵고 막막한 건 맞음. "무슨 이론·근거로 판단하지, 리뷰어가 받아줄까" 고민됨
- 하지만 **방법론은 이미 공통으로 정립되어 있음** → 거기서 응용하는 정도면 충분히 쓸 수 있는 방법론
- 제대로 된 근거로 논리를 제시하면 **내가 그 분야의 선행연구가 되는 것**. 지금은 그냥 도전함
- 오히려 **승산이 있음**: 선행연구가 없으면 리뷰어도 심사할 기준이 없음. 뉴로사이언스처럼 정답 없는 분야는 심사가 강하게 안 들어옴 (잘못 반박했다 역풍 맞을 수 있어서)
- "본인이 제일 잘 아는 거니까 강하게 주장하면 된다"
- 덧붙인 사례: 벡터바이오 시절 30억 과제(벡터 6억) — 키넥트 + 머신비전으로 사물 조작 시 손 동작 메시 추출. 당시엔 말도 안 되는 연구 같았지만 **ECCV 게재**. KAIST 랩 수준이 높아 따라가기 어려웠다는 소회

> 아래는 같은 화자(참석자 3)로 전사된 다른 질문들. 본인 질문이 아니면 수정할 것.

### Q. Visual3D 라이선스 1,000만 원이면 계속 무료 업데이트?
- 영구 사용 가능. 무료 업데이트는 **1년**. 이후 업데이트는 유료라 보통 기존 버전 계속 씀. 버전 간 큰 차이 없음

### Q. 논문의 Simi 마커리스는 OpenCap과 비슷한가?
- **원리는 동일**. 차이는 Simi가 카메라 8대 + 케이블로 워크스테이션 하나에서 완벽 제어 → 정확도·수집 효율 ↑, 10시간 연속 레코딩 가능
- 비용 규모: 스토리지 **100TB**가 일주일이면 참 (FHD × 8대 × 300Hz면 10분에 수 TB). 풀 사양 워크스테이션(5090×4, RAM 512GB)은 ~1억, 현실적으론 2~3천만 원
- Simi는 **수억 들여도 쓸 가치가 있는 랩**에, 그게 어려우면 **대안이 OpenCap**. Simi는 벡터바이오 랩, 적외선 모캡은 학교 랩에 있음

### Q. 한국 대학원 vs 해외 대학원, 배움의 차이?
- 반은 맞고 반은 틀림. **랩에 따라 다름**. 미국은 평균적으로 랩이 크고 인프라가 좋아 "확률적으로" 좋은 환경이 보장되는 정도
- 국내에서 압도적으로 잘하는 곳으로 **서울대 스포츠공학 (안주은 교수님으로 전사됨)**, **인천대 강현주 교수님** 랩을 언급 (전사 기준, 이름 확인 필요). "나머지는 비슷하다"는 리스크 있는 발언

### 로봇·피지컬 AI와 인간 움직임
- 보스턴다이나믹스 휴머노이드, AGT의 로봇 댄스 영상 → 로봇공학자 눈엔 대단하지만 생체역학자 눈엔 "누가 봐도 로봇"
- 인간 움직임은 **불완전해서 완전함**: 같은 input에 늘 다른 output → 상황·환경에 맞춘 최적 타이밍 → 아름다움. 로봇은 관중 함성·바닥 상태까지 고려한 "의지"가 없음
- 힘·스피드는 로봇이 이미 인간을 이김. 2040년쯤 올림픽에 로봇 축구 등장 가능. **인간이 이기는 유일한 영역 = 움직임의 질**
- → 생체역학·영상분석 연구자가 피지컬 AI 시대에 할 일이 오히려 많음 (기계공학·로봇·AI 전공과 협업)
