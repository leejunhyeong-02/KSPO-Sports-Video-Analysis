## 1부. 데이터 → 의미

### 1. 뼈대 추출·각도 계산은 더 이상 기술이 아니다
- 카메라로 뼈대, 관절 각도, 보행 속도, 케이던스를 뽑는 것은 AI로 코드 짜면 금방 구현되는 수준
- 러닝 앱, 야구 아카데미, 대학 축구부 GPS 활용("누가 몇 km 뛰었나" = *범인 찾기*)은 모두 표면 데이터에서 멈춤
- 경쟁력은 **그 데이터가 이 사람에게 무슨 의미인지** 제시하는 다음 단계
  - 예: 파킨슨 환자 500~1,000명 보행 데이터를 학습 → 촬영만으로 정상/파킨슨 판별
  - 강사 견해: 국내에 이 수준까지 간 곳은 아직 없음

### 2. 데이터 vs 정보 (손흥민 프리킥 사진 예시)
- 사진 전체 = 데이터, 내가 필요한 부분 = 정보
- 사람은 관심 대상에 초점, AI는 관중·배경까지 모두 정보로 처리
- 이 처리량 차이 때문에 데이터가 많아지면 AI가 필요

### 3. 빅데이터와 AI
- 빅데이터 기준은 분야마다 다름 — 생체역학에서는 **약 500명**이면 빅데이터로 볼 수 있음
- 정의: "내 역량으로 분석이 안 되는 양"
- 빅데이터 분석 도구 = AI(머신러닝·딥러닝) → **예측 모델**(교체 시점, 피로도, 구속 등)까지 가야 함
- 단, 순수 과학 연구는 소수 피험자(1~20명)로도 충분히 의미 있음 — 목적에 따라 선택

### 4. 표준화(normative data)가 되는 것 / 안 되는 것
- **선운동**(몸 전체를 하나의 물체로 본 이동 속도 등): 표준화 가능
- **각운동**(분절·관절 회전, 개인 신체 특성 반영된 메커닉): 평균 내서 표준화하면 위험
- 예: 투수 스트라이드 넓게 vs 좁게 → 정답 없음, 신체 특성에 따라 다름
- 벡터바이오 사례 (질의응답)
  - 물리 법칙(kinematics · kinetics · F=ma)에 근거해 "잘했다/못했다"를 말할 수 있는 변인 **약 30개**를 4년간 리서치로 도출
  - 그 변인들만 표준화
  - 이후 AI 적용 → kinematic 데이터만으로 구속 예측, 메커닉 수정 효과 추정

### 5. 현장·협업에 대한 태도
- 엘리트 선수 메커닉을 데이터만으로 함부로 수정하면 안 됨
- 코치·선수의 경험은 데이터로 대체 불가 → 그들이 원하는 것을 과학적으로 검증해 주는 방식으로 접근
- 스킬코치와 바이오메카니스트: 서로의 영역을 어느 정도 공부하되 선은 넘지 않기 (질의응답)
- 커리어
  - 프로구단 Hawk-Eye 도입 확대, 그러나 이를 분석해 솔루션을 만들 인력은 거의 없음
  - 변경석 박사(벡터바이오) 사례, 롯데 박사급 포지션 언급

### 6. 논문과 AI
- AI 활용 가능. 단, AI의 분석을 본인이 이해·검증할 수 있는 수준이어야 함

## 2부. OpenCap (3D 마커리스 pose estimation)

### 개요
- 스탠포드 운동역학 연구실 개발, 무료
- 컴퓨터 비전 + 딥러닝 + 근골격 시뮬레이션 결합
- **아이폰 2대 스테레오 방식** (두 영상을 조합해 3D 재구성)
- 클라우드 처리, 웹(opencap.ai)에서 계정별 저장·다운로드
- 수집 데이터로 계속 재학습됨

### 마커 기반 vs 마커리스

| | 마커 기반 (적외선 3D) | 마커리스 (OpenCap) |
|---|---|---|
| 정확도 | 오차 거의 없음 | AI 추정이라 상대적으로 낮음 (옷 속 뼈 위치는 추정 불가) |
| 비용·속도 | 수억 원, 느림 | 저렴·빠름, 야외 가능 |
| 권장 용도 | 엘리트 고정밀 메커닉 분석 | 짐·아카데미, 일반 고객·환자 피드백 |

- 엘리트 분석 시: 마커 기반으로 먼저 측정 → 마커리스와 비교 → 해당 동작에서 충분히 정확하면 그때 마커리스 사용

### 촬영 원칙
- **머리부터 발끝까지 전신이 화면에 나와야 함** (모델이 전신 이미지로 학습됨)
- 카메라는 **정면 기준 30~45° 대각선** 배치 권장
  - 순수 측면 촬영 → 반대쪽 몸 정보가 없어 데이터 떨림·오차 증가
  - 시상면(sagittal plane) 굴곡·신전 동작이라도 측면 촬영이 더 좋지 않음 (직관과 반대)
- 달리기: 옆으로 지나가지 말고 **카메라를 향해 달려오게** 촬영
- 전신이 안 잡히는 동작은 핵심 퍼포먼스 구간만 전신이 나오게 설계
- 동적 촬영 전 **정적 트라이얼(기본 해부학적 자세)** 먼저 촬영
- 화면에 두 명이 있으면 가까운 사람을 추적하며 오류 → 촬영 중 다른 사람 진입 금지
