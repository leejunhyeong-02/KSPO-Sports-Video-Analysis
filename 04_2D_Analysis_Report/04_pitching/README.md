# ⚾ Pitching Motion Analysis Interactive Site Guide

index.html 을 더블클릭하면 열립니다. videos/ 폴더는 index.html 과 같은 위치에 두세요 (A=이상민, B=신정환, C=이준형, 숫자=투구 회차).


- **선수 코드**:
  - A: 이상민 (좌완)
  - B: 신정환 (우완)
  - C: 이준형 (우완)
  - 숫자: 투구 회차 (1~5구)
- **실행 방법**: index.html을 웹 브라우저(Chrome, Edge 등)로 열면 조원 피드백 리포트 및 상호작용 차트가 로드됩니다.
